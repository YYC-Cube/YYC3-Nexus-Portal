### 3.1 `components/ui/chart.tsx`（9个错误）

| 行号  | 错误码   | 描述                                            |
|-------|----------|-------------------------------------------------|
| 109   | TS2339   | Property 'payload' does not exist               |
| 114   | TS2339   | Property 'label' does not exist                 |
| 182   | TS7006   | Parameter 'item' implicitly has 'any' type      |
| 182   | TS7006   | Parameter 'index' implicitly has 'any' type     |
| 260   | TS2344   | Type '"payload"' does not satisfy constraint    |
| 266   | TS2339   | Property 'length' does not exist on type '{}'   |
| 278   | TS2339   | Property 'map' does not exist on type '{}'      |
| 278   | TS7006   | Parameter 'item' implicitly has 'any' type      |

**根因**: recharts 3.x 类型定义与 shadcn/ui chart 组件不兼容
**修复方案**: 更新 chart.tsx 组件的类型定义或升级 recharts

### 3.2 `components/ui/resizable.tsx`（5个错误）

| 行号  | 错误码   | 描述                                                |
|-------|----------|-----------------------------------------------------|
| 12    | TS2339   | Property 'PanelGroup' does not exist                |
| 14    | TS2339   | Property 'PanelGroup' does not exist                |
| 35    | TS2339   | Property 'PanelResizeHandle' does not exist         |
| 39    | TS2339   | Property 'PanelResizeHandle' does not exist         |
| 52    | TS2339   | Property 'PanelResizeHandle' does not exist         |

**根因**: react-resizable-panels 4.x 导出结构变更
**修复方案**: 检查该库的命名导出，更新 import 语句

### 3.3 `components/code-demo.tsx`（1个错误）

| 行号 | 错误码  | 描述                                               |

**根因**: Spotlight 组件 props 类型不匹配
**修复方案**: 移除 `fill` prop 或更新 Spotlight 组件类型

### 3.4 `lib/i18n-client.ts`（1个错误）
